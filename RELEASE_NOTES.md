# BaldojnyiDownloader 0.5.1.2

## Виправлено

- Виправлено фінальне створення MP4 на Windows: після успішного завантаження та об’єднання потоків застосунок більше не зупиняється на проміжному MKV через повторне читання файла.
- Шляхи Windows із пробілами та українськими символами передаються зі `yt-dlp` у структурованому вигляді.

## Надійність

- Для конвертації застосунок використовує перевірені метадані готового файла безпосередньо від `yt-dlp`; `ffprobe` залишається резервним шляхом для нестандартних джерел.
- Версію hotfix піднято до публічної `0.5.1.2` та внутрішньої Tauri/SemVer `0.5.12`.
