# BaldojnyiDownloader 0.6.5.0

## Виправлено

- Відновлено завантаження YouTube після масових помилок 403, які почалися у stable yt-dlp `2026.07.04`. Керований runtime переходить на офіційний nightly-канал, який сам yt-dlp рекомендує звичайним користувачам для своєчасної сумісності із сайтами.
- Після безпечного стартового встановлення застосунок під час запуску, але не частіше разу на добу, сам перевіряє офіційний nightly-канал. Тому свіжі виправлення сайтів з’являються без очікування нового релізу BaldojnyiDownloader і без ручного оновлення через Terminal.
- Оновлення приймається лише з точного офіційного шляху `yt-dlp/yt-dlp-nightly-builds`: GitHub SHA-256 має збігтися з опублікованим upstream-файлом `SHA2-256SUMS`, завантажений файл повторно перевіряється на диску та повідомляє очікувану версію до атомарної заміни. Попередній робочий файл зберігається при будь-якій помилці.

## Перевірено

- Точне відео `I5FsfhPhtT4` відтворило проблему: stable завершився 403, а nightly повністю завантажив і об’єднав відео з аудіо.
- Додано автоматичні перевірки постійного nightly-каналу, точних офіційних URL, версій і подвійного узгодження SHA-256.
