# yt-dlp BD 0.3.0.0

## Що нового

- Додано локальну історію завантажень із датою, розміром і шляхом до готового файла.
- Мініатюри зберігаються локально й залишаються доступними без інтернету.
- З історії можна повторити завантаження з тими самими параметрами.
- Додано перевірку, чи готовий файл досі доступний на диску або зовнішньому накопичувачі.
- Версія у застосунку тепер відповідає публічній версії релізу.
- Посилання в головному полі можна очистити одним натисканням.

## Важливо

Застосунок автоматично перевіряє наявність нових версій. Для першого встановлення завантажте інсталятор своєї платформи зі сторінки GitHub Release.
