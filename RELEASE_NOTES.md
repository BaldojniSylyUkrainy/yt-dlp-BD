# BaldojnyiDownloader 0.4.0.0

## Що нового

- Після успішного завантаження та завершення всієї обробки застосунок подає тихий системний звуковий сигнал. При помилці або скасуванні сигнал не відтворюється.
- Назва GitHub Release тепер відповідає назві інсталяційних файлів: `BaldojnyiDownloader 0.4.0.0`.

## Покращено

- Progress bar на стартовому екрані та відсоток під ним відцентровані відносно загальної композиції.
- Головний екран одразу пояснює, що застосунок працює з YouTube, Instagram, Twitter та багатьма іншими сайтами.

## Успадковано з 0.3.3.0

- Loading screen тепер з’являється до перевірки локальних компонентів, без 10–20 секунд порожнього сірого вікна на macOS.
- Файли на сторінці GitHub Release тепер мають стабільні та зрозумілі назви з назвою застосунку, версією і платформою.
- Інсталятор macOS називається `BaldojnyiDownloader-0.4.0.0-Mac-Apple-Silicon.dmg`.
- Інсталятор Windows називається `BaldojnyiDownloader-0.4.0.0-Windows-x64-Setup.exe`.
- Підписаний пакет автоматичного оновлення macOS також використовує читабельну назву.

## Auto updater

- `latest.json` автоматично посилається на нові назви пакетів для macOS і Windows.
- Криптографічні підписи `.sig` перейменовуються разом із відповідними пакетами та залишаються обов’язковими.
- Release workflow перевіряє наявність усіх інсталяторів, updater-пакетів і підписів перед створенням draft release.

Користувачам уже встановлених версій нічого змінювати не потрібно: застосунок і надалі перевіряє постійне посилання `latest.json` та автоматично завантажує правильний пакет своєї платформи.

## Виправлено

- Повільний запуск `yt-dlp --version` більше не виконується в macOS UI-потоці й не блокує перший кадр застосунку.
- Наявність yt-dlp під час старту перевіряється без запуску важкого standalone-бінарника; точна версія кешується після фонової перевірки офіційного релізу.
