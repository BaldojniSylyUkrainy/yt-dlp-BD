# yt-dlp BD 0.3.2.0

## Що нового

- Застосунок більше не показує порожнє сіре вікно під час запуску: стартовий екран з’являється майже миттєво.
- Перевірка оновлень стала надійнішою: застосунок повторює її після запуску, після відновлення інтернету та під час тривалої роботи.
- Доступне оновлення тепер відкривається в окремому зрозумілому вікні з описом змін і прогресом встановлення.
- Якщо перевірка оновлень не вдалася, застосунок показує причину й дозволяє повторити її вручну.
- Release notes відображаються однаково в застосунку та на сторінці GitHub Release.
- Головна сторінка GitHub тепер містить прості інструкції зі встановлення для macOS Apple Silicon і Windows x64.

## Виправлено

- Локальна історія та налаштування більше не блокують появу першого кадру застосунку.
- Перевірка оновлень більше не завершується назавжди після одного короткого таймауту.

## Встановлення

Нові користувачі можуть завантажити інсталятор для своєї платформи зі сторінки GitHub Release. Уже встановлені копії отримають пропозицію автоматичного оновлення.
