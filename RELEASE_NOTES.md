# BaldojnyiDownloader 0.5.1.1

## Виправлено

- Відновлено автоматичне встановлення Deno на Windows. Застосунок тепер правильно читає офіційний SHA-256 із Windows checksum-файла Deno у форматі PowerShell.
- Перевірка також зберігає підтримку стандартного формату `SHA256 filename`, який Deno використовує для macOS.

## Надійність

- Інсталятор приймає лише повний 64-символьний SHA-256 і відхиляє порожні, пошкоджені або неоднозначні checksum-файли.
- Версію hotfix піднято до публічної `0.5.1.1` та внутрішньої Tauri/SemVer `0.5.2`, щоб автоматичне оновлення коректно вважало збірку новішою за `0.5.1.0`.
