# BaldojnyiDownloader 0.4.1.0

## Виправлено

- Кнопка **«Оновити зараз»** у вікні автоматичного оновлення тепер постійно рожева й добре помітна без наведення курсора.
- Під час завантаження оновлення кнопка зберігає рожевий фон і читабельний контрастний текст.

## Release workflow

- Підказка для release tag більше не містить номера конкретної версії, який міг застаріти.
- Поле release tag тепер одразу заповнюється актуальним значенням `v0.4.1.0`.
- Додана автоматична перевірка узгодженості версії в package, Cargo, Tauri, release notes і поточній документації.
