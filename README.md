# yt-dlp BD — Baldojnyi Downloader

Застосунок з українським інтерфейсом для простого завантаження відео, аудіо та субтитрів. Вставляєте посилання, обираєте потрібний формат — решту програма робить сама за допомогою офіційного [yt-dlp](https://github.com/yt-dlp/yt-dlp).

[**Завантажити останню версію для macOS або Windows**](https://github.com/BaldojniSylyUkrainy/yt-dlp-BD/releases/latest)

## Що вміє застосунок

- завантажує відео, аудіо, субтитри, плейлисти та каруселі;
- показує прев’ю й перевіряє посилання перед запуском;
- дозволяє обрати якість відео або аудіоформат;
- створює сумісний H.264/AAC MP4 для QuickTime Player і відеоредакторів;
- показує окремий прогрес підключення, завантаження, об’єднання та конвертації;
- подає тихий системний сигнал, коли завантаження й обробка повністю завершені;
- контролює вільне місце й безпечно зупиняється, якщо диск заповнюється;
- зберігає локальну історію, прев’ю та параметри для повторного завантаження;
- сам встановлює й оновлює yt-dlp, ffmpeg/ffprobe та Deno;
- повідомляє про нову версію застосунку й встановлює її автоматично.

## Встановлення

Відкрийте сторінку [останнього GitHub Release](https://github.com/BaldojniSylyUkrainy/yt-dlp-BD/releases/latest), розгорніть **Assets** і завантажте файл для своєї платформи.

### macOS — Apple Silicon

Підтримуються Mac із процесорами M1, M2, M3, M4 та новішими, macOS 12.3 або новіша.

1. Завантажте файл із назвою `BaldojnyiDownloader-…-Mac-Apple-Silicon.dmg`.
2. Відкрийте `.dmg` і перенесіть **yt-dlp BD** у папку **Applications**.
3. Запустіть застосунок із папки **Applications**.

Збірка підписана Developer ID і нотаризована Apple. Версії для Intel Mac поки немає.

### Windows — x64

1. Завантажте файл із назвою `BaldojnyiDownloader-…-Windows-x64-Setup.exe`.
2. Запустіть інсталятор і завершіть встановлення.
3. Відкрийте **yt-dlp BD** через меню Start.

Windows SmartScreen може вперше показати попередження про невідомого видавця. Інсталятор перевіряється вбудованим ключем оновлення застосунку, але окремого Windows Authenticode-сертифіката поки немає.

## Як користуватися

1. Скопіюйте посилання на відео, допис, плейлист або карусель.
2. Вставте його в поле **Посилання**.
3. Оберіть відео чи аудіо, якість і папку збереження.
4. Натисніть **Завантажити**.
5. Не закривайте вікно, доки застосунок не завершить усі етапи обробки.

Якщо сайт вимагає авторизацію, перевірку віку або anti-bot підтвердження, застосунок запропонує використати cookies із вашого браузера.

## Оновлення

Застосунок автоматично перевіряє нові версії. Коли оновлення доступне, він показує, що саме змінилося, завантажує підписаний пакет і перезапускається після встановлення.

Повний опис поточної версії є у файлі [RELEASE_NOTES.md](RELEASE_NOTES.md) та на сторінці [GitHub Releases](https://github.com/BaldojniSylyUkrainy/yt-dlp-BD/releases).

## Приватність і відповідальність

Історія завантажень і кешовані прев’ю зберігаються локально на вашому комп’ютері. Завантажуйте лише матеріали, на які маєте відповідні права.

## Розробка

Потрібні Node.js, Rust і системні залежності Tauri 2.

```bash
npm install
npm run tauri dev
```

Перевірки перед змінами:

```bash
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

Runtime-компоненти завантажуються лише з офіційних джерел: [yt-dlp releases](https://github.com/yt-dlp/yt-dlp/releases), [Deno releases](https://github.com/denoland/deno/releases), [Martin Riedl’s FFmpeg Build Server](https://ffmpeg.martin-riedl.de/) для macOS та [yt-dlp/FFmpeg-Builds](https://github.com/yt-dlp/FFmpeg-Builds) для Windows. Контрольні суми перевіряються перед встановленням.
